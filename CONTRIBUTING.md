# Contributing to WordLoop

Bug reports, translation feedback and small improvements are welcome.

- Open a [bug report](https://github.com/diegoderivas/WordLoop/issues/new?template=bug_report.md) with Android version, app version, steps and expected versus actual results.
- [Suggest an improvement](https://github.com/diegoderivas/WordLoop/issues/new?template=feature_request.md) and describe what it would help you do.
- Use synthetic vocabulary in screenshots and reproduction steps. Redact account details, file paths and device identifiers from logs.
- For code changes, fork the repository, keep your change focused, and run `./gradlew :app:testDebugUnitTest`. Add an emulator result when a change affects storage, navigation or Android integrations.

Discuss broader design, migration or scheduling changes in an issue before starting implementation.
